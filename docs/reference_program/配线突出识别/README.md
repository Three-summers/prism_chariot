# 双导线凸起检测系统 (Python版)

基于 Python + PyQt5 + OpenCV 的双导线光斑追踪凸起检测桌面应用。

## 功能

- 🎬 视频文件加载 + 实时逐帧监测
- 📷 摄像头实时采集
- 📁 静态图片加载
- 📏 画线选点：水平拖动鼠标穿过光斑，自动识别L/B/R三个光斑位置
- 📊 实时偏移趋势图（纯QPainter自绘制）
- 📈 帧率实时显示
- 🎮 视频进度条拖动
- ⚠ 预警/报警阈值调节 + 灵敏度
- 📄 CSV数据导出
- ⌨ 快捷键：空格启停、1/2切换导线、Esc停止

## 安装与运行

```bash
pip install -r requirements.txt
python main.py
```

## 使用说明

1. **加载源**：点击 图片/视频/摄像头 加载画面
2. **画线选点**：点击画线选点，在画面上水平拖动鼠标画一条线穿过光斑。系统自动识别线上三个最亮的光斑位置（左/中/右）
3. **切换导线**：对导线1和导线2分别画线选点
4. **开始监测**：点击开始监测，系统逐帧追踪光斑位置，实时计算凸起偏移
5. **调节阈值**：右侧面板可调节预警/报警角度阈值和灵敏度

## 算法

- **findSpotsOnLine**：画线Y坐标上，垂直±12像素采样亮度，分左中右三段各自最亮点±4邻域加权质心 → 三个光斑的精确位置
- **trackSpot**：监测时以标定位置为中心，±50像素搜索范围内亮度加权质心追踪每个光斑
- **凸起 = 中间光斑(B)Y坐标偏离左右两端(L-R)基线的像素偏移 × 灵敏度 = 角度(°)
