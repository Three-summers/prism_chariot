# Life Sensing Console Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build a runnable React + TypeScript front-end slice for the life-sensing industrial monitoring page, with placeholder navigation for the other modules.

**Architecture:** A Vite React single-page app with small presentational panels and local mock state. Runtime assets live under `public/resources`; reference material remains under `docs`. The page uses CSS grid, inline SVG/CSS overlays, and lightweight mock trend data without a backend.

**Tech Stack:** Vite, React, TypeScript, CSS, Lucide React.

## Global Constraints

- Preserve Chinese labels and the dark industrial-console visual language from `docs/images/生命感知.png`.
- Keep reference programs and reference screenshots under `docs/`; only runtime assets move to `public/resources`.
- Other module tabs are placeholders and must not imply implemented functionality.
