光棱战车:AMHS轨道影像辨识系统
Windows 离线版使用说明

一、系统要求

1. Windows 10 或 Windows 11，64 位系统。
2. 推荐使用最新版 Microsoft Edge 或 Google Chrome。
3. 系统运行期间不需要互联网连接，也不需要安装 Node.js。

二、启动系统

1. 先完整解压交付压缩包，不要直接在压缩包内运行。
2. 双击“启动系统.bat”。
3. 默认浏览器会自动打开 http://127.0.0.1:18080/。
4. 如果浏览器没有自动打开，请手动输入上述地址。

三、停止系统

双击“停止系统.bat”。关闭浏览器窗口不会自动停止本地服务。

四、使用边界

1. 系统只监听本机 127.0.0.1，不会对局域网或互联网开放。
2. 用户选择的图片、视频和目录均在本机浏览器中处理，不会上传。
3. 当前版本没有后端数据库；刷新页面或关闭系统后，临时 CASE 和结案编辑内容不会集中保存。
4. 生命感知当前使用模拟数据源。

五、故障排查

1. 页面打不开：先双击“停止系统.bat”，再重新启动。
2. Windows 防护提示：确认压缩包来自可信交付方，然后允许 Caddy 本地运行。
3. 端口被占用：确认本机 18080 端口没有被其他程序使用。
4. 启动失败日志位于“.runtime\caddy-error.log”。
5. 请保持 app、server、启动脚本和停止脚本的相对位置不变。

六、版本信息

应用版本、构建提交、离线服务器版本和构建日期详见“版本信息.txt”。
